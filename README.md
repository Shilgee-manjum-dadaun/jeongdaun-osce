# 정다운암기법 — OSCE Quiz

React + Vite + Tailwind CSS SPA for OSCE mnemonic practice.

## Develop

```bash
npm install
npm run dev
```

## Build (GitHub Pages)

```bash
npm run build
```

Site base path: `/jeongdaun-osce/`  
Target URL: https://shilgee-manjum-dadaun.github.io/jeongdaun-osce/

Push to `main` to deploy via `.github/workflows/pages.yml`.
In the repo Settings → Pages, set Source to **GitHub Actions**.
